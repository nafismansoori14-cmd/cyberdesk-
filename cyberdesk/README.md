# CyberDesk

CyberDesk is a production-grade Cyber Cafe Management SaaS scaffold with a backend API, admin dashboard, and client portal.

## Workspace setup

1. Install dependencies: `pnpm install`
2. Start services: `pnpm --recursive dev`

## Structure

- `apps/backend` - Node.js + Express API
- `apps/admin-web` - React admin dashboard
- `apps/client-web` - React client portal

## Notes

This workspace is a scaffold for a commercial Cyber Cafe Management System with Socket.io, JWT auth, pricing, session management, and analytics.
